# Problem sets

Each `.json` file in this folder is one problem set. Students open a set with a link like:

```
https://<your-site>/?set=circuit-review
```

The part after `?set=` is the file name without `.json`. Use lowercase letters, numbers and dashes only.

## Adding or updating a set
1. In the app, open the **Sets** tab. Add circuits, choose what each problem asks for, and use **Preview as a student** to try it.
2. Click **Download set file**.
3. On GitHub, open this `sets` folder. Click **Add file → Upload files**, drop the file in, and click **Commit changes**. Uploading a file with the same name replaces the old version.
4. After about a minute, share the link shown in the app.

To edit a published set later, use **Open from site** in the Sets tab (type its name), change it, and download it again.

When a set file changes, students' saved progress for that set starts over.

## What students see
- One problem at a time, with your instructions, Previous/Next buttons, and numbered dots to jump around.
- **Predict** problems: only the tools for the marks you required (wire colors, arrows, rays). For arrows, students press *Add arrow*, tap a bulb or a spot on a wire, and pick a direction from a small pop-up. *Let it settle* and the *Answer* each appear only if you allowed them, and only after they press Check, so students commit to a prediction first.
- **Explore** problems: the circuit with the "watch it settle" controls and nothing to mark.
- A summary at the end that lists each problem as *correct on the first check*, *correct after N checks*, *not correct yet* or *not checked*.

Progress is kept in the student's browser, so reloading the page doesn't lose their work. Nothing is sent anywhere.
